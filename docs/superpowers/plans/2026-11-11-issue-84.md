## Decisions made at planning (gate 1: the owner can change any of these)

1. **The subtitle "Experiments, agents, and open-source ideas." is removed.** preview-d's Lab has no subtitle, and its head-to-stack gap (51px, `.ix-h+*`) has no room for one. #81 removed Passions' "Beyond my Mac" subtitle for the same reason. The ticket does not name the subtitle, so this is the decision most likely to be wrong. If the owner keeps it, it sits as `<p className="mt-2 text-body text-ink-subtle">` under the head, and the stack gap becomes 51px below the subtitle.
2. **The wrapper becomes the 1004px page column with a rule, not the 960px `Section`.** That puts the head's left edge and the rule in line with the sections above and below it. With the default motion the stack is capped at `max-w-[900px]` and centred, so it does not move. Under reduced motion at 768px and wider, the grid fallback has no cap, so it widens from 912px to 956px at 1440. preview-d's grid is 956px too. Gate 2 states the measured widths.
3. **The head class string is copied, not extracted.** "The same classes" in the Done when allows this, and a shared `SectionHead` component would touch `Timeline.tsx`, `Education.tsx` and `Passions.tsx`, which this ticket does not own. The class string is the one in `Timeline.tsx` lines 10 to 11, character for character.
4. **The head is not wrapped in `Reveal`.** No sibling head fades in, and the `Reveal` div only existed to hold the head and subtitle. The `Reveal` around "See all projects" stays.

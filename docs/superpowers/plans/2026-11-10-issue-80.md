Rejected: showing `shortDesc` on every card (decision 25 says LAND only; the other four would change copy), and a hard-coded `title === "LAND"` check in the component (the way `build5.py` does it; it puts content in the component).
2. **No variants.** The ticket is visual, but the design is settled: preview-d is the owner's pick (decisions 24, 25, 31). The build wires it in; it does not build preview variants.
3. **"See all projects" needs no code change.** On main, `TheLab.tsx` already wraps the link in `Reveal className="flex justify-center"` inside the 960px `Section`, and the stack is `mx-auto max-w-[900px]`, so the link centre and the stack centre are the same x. The 28px offset was only in the preview. The build measures it (Task 1 Step 5) instead of editing it. If the measurement shows an offset, stop and report; do not invent a fix.

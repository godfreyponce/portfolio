## Decisions made at planning (gate 1 is pre-approved; listed so gate 2 can check them)

1. **The tagline keeps its hover scramble (#37).** The static preview shows plain text, but it cannot show a hover effect, and decision 16's list of hero changes does not drop it. `ScrambleText` stays; only its size and colour change to the spec's (`text-body`, line height 1.4, `ink-faint`).
2. **"Base column" is one token, not a change to `Section.tsx`.** `--container-page: 1004px` in `@theme` gives the `max-w-page` utility (956px content plus `px-6` gutters, genesiating's measured column). The hero uses it now; #79 to #82 adopt it. `Section.tsx` keeps 960px so the sections below do not move in this ticket.
3. **"Base type" is the mono face.** `--font-mono` becomes Geist Mono (the preview's mono everywhere: hero email, loss graph readout, footer). This changes the face of four existing `font-mono` spots below the hero; sizes stay. If the owner rejects that at gate 2, the fallback is a hero-only token.
4. **The Soccer link keeps firing `highlight-soccer`**, so the live Passions pulse (unchanged until #81) still works.
5. **Reduced-motion scroll is one CSS rule.** `html { scroll-behavior: smooth }` exists today, so `scrollIntoView({behavior:"auto"})` would still be smooth. A `prefers-reduced-motion: reduce` rule sets `scroll-behavior: auto` on `html`, and the Soccer handler calls `scrollIntoView()` with no options. This also makes the footer's `#top` link instant under reduced motion.
6. **Orphans removed:** `About.tsx`, `SimpleBackground.tsx`, the `cursor-github`, `cursor-linkedin`, `cursor-gmail` utilities, the `.email-google` rules and its four keyframes, `.hover-bubble`, and the tokens `--color-brand-github` and `--color-google-*`. `tactile-link` stays (Footer uses it). `public/godfrey_headShot.JPG` stays (it is the crop source per decision 12); gate 2 mentions it is now unused.
7. **The portrait is already tracked.** The issue says `public/godfrey_portrait.jpg` is untracked and must ride in this ticket's commit; chore commit 77de695 already added it to main. Gate 2 says so.
8. **Check port is not 3000** (owner dispatch, issue #77). The Done-when names localhost:3000; the build uses its own free port. Gate 2 says so.

## Review Focus

1. **Copy failure path.** If `navigator.clipboard` is missing or `writeText` rejects, the label still reads "copied" (the preview does the same). Expected: no thrown error, label resets after 1.6 s. Check by reading the handler.
2. **Double click on "copy".** A second click inside 1.6 s restarts the timer; the label must not flip back early. Check: click twice about 1 s apart; the label stays "copied" until about 1.6 s after the second click.
3. **Narrow widths between 768 and 1003px.** The text column shrinks to about 300px at 768. Expected: the action row wraps or fits without sideways scroll. Check in a 768px iframe.
4. **Shadow seam.** `main` carries `shadow-lid` (offset 24px, blur 48px). If it paints over the header's bottom edge, a faint dark band shows under the portrait. The header gets `z-20` so it paints over that shadow. Check at 1440 that the portrait's bottom edge has no grey band.
5. **Unmount during the 1.6 s timer** (fast refresh, route change). Expected: the timer is cleared in an effect cleanup; no state update after unmount.

# Issue #16: Profile README neofetch panel legibility — Implementation Plan

> **For agentic workers:** Execute via `/build-ticket 16` in a fresh window. Steps use checkbox (`- [ ]`) syntax for tracking. This plan has a hard STOP at Task 5 (owner picks a variant) and another before any commit/push (owner reviews first).

**Goal:** Make the neofetch panel text legible at GitHub's rendered README width (~830-900px) while the braille portrait stays the hero, for both dark and light themes.

**Architecture:** The shipped SVG is 1668px wide; GitHub scales it to ~838px, so 16px panel text reads at ~8px. The only lever is the ratio `T_SIZE / total_width`. We regenerate the SVGs from the preserved generator with three parameterizations (bigger panel type, narrower composition, stacked geometry), preview all three at GitHub's true render width, owner picks, winner ships to `godfreyponce/GodfreyPonce`.

**Tech Stack:** Python 3 scratch scripts (no deps), SVG, one throwaway preview HTML in `public/`, `gh` CLI, Chrome automation for visual verify.

## The math (why these three variants)

Effective on-GitHub panel size = `T_SIZE × (838 / W_total)` where 838px is the reference README card content width (ticket says ~830-900). Shipped: `16 × 838/1668 = 8.0px`. Target: ≥ ~12.5px.

| Variant | Layout | P_SIZE | T_SIZE/T_LH | Panel file | W_total | Panel effective | Portrait effective |
|---|---|---|---|---|---|---|---|
| shipped | classic | 16 | 16/22 | unwrapped (52ch) | 1668 | 8.0px | 532px |
| A "big type" | classic | 16 | 26/34 | wrapped (33ch) | ~1684 | ~12.9px | ~527px |
| B "compact" | classic | 12 | 20/27 | wrapped (33ch) | ~1299 | ~12.9px | ~513px |
| C "stacked hero" | stacked | 16 | 18/25 | unwrapped (52ch) | ~1108 | ~13.6px | ~801px |

Widths follow from the generator's geometry: `W = 24 + 96·ADV + 56 + maxlen·TEXT_ADV + 24` (classic) or `W = 24 + 96·ADV + 24` (stacked), with `ADV = 11.04·P_SIZE/16` and `TEXT_ADV = 9.7·T_SIZE/16` (both advances scale linearly with font size; the 16px values were measured in Chrome/macOS in #15).

Tradeoff notes for the owner at pick time: A keeps the shipped shape exactly; B shrinks the file and portrait slightly; C makes the portrait huge but the README card ~2× taller (pushes pinned repos down) and drops the card border/rounding (full-bleed canvas, as designed in #15's variant round).

One limit all three variants share: on **mobile** (README card ~370px) even the best lands ~6px — a static SVG can't be legible there while the portrait spans 96 braille columns. This ticket's acceptance is desktop width, so that's out of scope; if mobile legibility ever becomes a requirement, the fix is architectural (panel as native README text, e.g. a yaml code block GitHub highlights in both themes, beside a portrait-only image), not another size bump. Flag it to the owner at pick time and let them decide whether desktop-only is acceptable.

- [ ] **Step 1: Write `$SCRATCH/gen_svg.py`**

```python
#!/usr/bin/env python3
"""Braille portrait + neofetch panel SVG, sized for GitHub's README width.
usage: gen_svg.py <classic|stacked> <dark|light> <panel_file> <P_SIZE> <T_SIZE> <T_LH> <out.svg>"""
import html, os, sys

SCRATCH = os.environ["SCRATCH"]
ART = open(f"{SCRATCH}/portrait_d.txt").read().rstrip("\n").split("\n")   # 51 x 96

FONT = "Consolas, Menlo, monospace"

THEMES = {
  "dark":  dict(canvas="#0d1117", card="#161b22", border="#30363d",
                ink="#c9d1d9", key="#ffa657", val="#a5d6ff"),
  "light": dict(canvas="#ffffff", card="#f6f8fa", border="#d0d7de",
                ink="#24292f", key="#953800", val="#0a3069"),
}

def esc(s): return html.escape(s, quote=False)

def text_block(lines, x, y, size, lh, cls_lines=False):
    out = [f'<text xml:space="preserve" x="{x}" y="{y}" font-size="{size}">']
    for i, ln in enumerate(lines):
        dy = lh if i else 0
        if cls_lines and ln.startswith("  "):   # wrapped continuation -> value color
            out.append(f'<tspan x="{x}" dy="{dy}" class="v">{esc(ln)}</tspan>')
        elif cls_lines and ":" in ln:
            k, v = ln.split(":", 1)
            out.append(f'<tspan x="{x}" dy="{dy}"><tspan class="k">{esc(k)}:</tspan>'
                       f'<tspan class="v">{esc(v)}</tspan></tspan>')
        else:
            out.append(f'<tspan x="{x}" dy="{dy}" class="i">{esc(ln)}</tspan>')
    out.append("</text>")
    return "\n".join(out)

def build(layout, theme, panel, p_size, t_size, t_lh):
    t = THEMES[theme]
    adv = 11.04 * p_size / 16        # measured 11.04 @16px in #15; advances scale linearly
    text_adv = 9.7 * t_size / 16     # measured 9.7 @16px in #15
    art_w, art_h = 96 * adv, 51 * p_size   # portrait line-height = p_size so cells tile
    panel_w = max(len(ln) for ln in panel) * text_adv
    pad = 24
    body = []
    if layout == "classic":       # portrait left, panel right
        W = pad + art_w + 56 + panel_w + pad
        H = pad + art_h + pad
        panel_y = (H - len(panel) * t_lh) / 2 + t_size
        body.append(f'<rect width="{W}" height="{H}" rx="8" fill="{t["card"]}" stroke="{t["border"]}"/>')
        body.append(text_block(ART, pad, pad + p_size, p_size, p_size))
        body.append(text_block(panel, pad + art_w + 56, panel_y, t_size, t_lh, cls_lines=True))
    elif layout == "stacked":     # portrait on top, panel centered below
        W = pad + art_w + pad
        H = pad + art_h + 32 + len(panel) * t_lh + pad
        panel_x = (W - panel_w) / 2
        body.append(f'<rect width="{W}" height="{H}" fill="{t["canvas"]}"/>')
        body.append(text_block(ART, pad, pad + p_size, p_size, p_size))
        body.append(f'<line x1="{pad}" y1="{pad+art_h+16}" x2="{W-pad}" y2="{pad+art_h+16}" stroke="{t["border"]}"/>')
        body.append(text_block(panel, panel_x, pad + art_h + 32 + t_size, t_size, t_lh, cls_lines=True))
    else:
        sys.exit(f"unknown layout {layout}")
    style = (f'text{{font-family:{FONT};white-space:pre}}'
             f'.i{{fill:{t["ink"]}}} .k{{fill:{t["key"]};font-weight:600}} .v{{fill:{t["val"]}}}')
    return (f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 {W:.0f} {H:.0f}" '
            f'width="{W:.0f}" height="{H:.0f}">\n<style>{style}</style>\n'
            + "\n".join(body) + "\n</svg>\n")

if __name__ == "__main__":
    layout, theme, panel_file, p_size, t_size, t_lh, out = sys.argv[1:8]
    panel = open(panel_file).read().rstrip("\n").split("\n")
    open(out, "w").write(build(layout, theme, panel, int(p_size), int(t_size), int(t_lh)))
    print(out)
```

```python
#!/usr/bin/env python3
"""Assemble public/preview-16.html: shipped vs 3 variants at GitHub's README width."""
import base64, os

S = os.environ["SCRATCH"]

def uri(path):
    return "data:image/svg+xml;base64," + base64.b64encode(open(path, "rb").read()).decode()

VARIANTS = [
    ("Shipped today: panel reads at ~8px", "shipped"),
    ("A: big type classic (T=26, wrapped panel, ~12.9px effective)", "a"),
    ("B: compact classic (portrait 12px, T=20, ~12.9px effective)", "b"),
    ("C: stacked hero (full-width portrait, T=18, ~13.6px effective)", "c"),
]
THEMES = [
    ("dark", "#0d1117", "#30363d", "#c9d1d9"),
    ("light", "#ffffff", "#d0d7de", "#24292f"),
]
cards = []
for title, key in VARIANTS:
    for theme, page_bg, border, fg in THEMES:
        img = uri(f"{S}/{key}_{theme}.svg")
        cards.append(
            f'<section style="background:{page_bg};padding:24px 0">'
            f'<div style="width:838px;margin:0 auto;color:{fg};'
            f'font:14px -apple-system,sans-serif">'
            f'<p style="margin:0 0 8px">{title} [{theme}]</p>'
            f'<div style="border:1px solid {border};border-radius:6px;padding:24px">'
            f'<img src="{img}" style="max-width:100%;height:auto;display:block">'
            f'</div></div></section>')

html = ('<!doctype html><meta charset="utf-8">'
        '<title>#16 neofetch panel variants</title>'
        '<body style="margin:0">' + "\n".join(cards))
open("public/preview-16.html", "w").write(html)
print("public/preview-16.html")
```

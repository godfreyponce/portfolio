3. **Alt text is fixed in this plan** (see Step 3), written from looking at each image. The builder copies it verbatim.
4. **Odd cell in the reduced-motion desktop grid.** `ProjectStack.tsx:203-225`: when the stacked scroll layout is off (SSR first paint, phones, or reduced motion), the layout is a grid: the lead card spans both columns, then the rest plus the GitHub tile fill a 2-column grid at `md`. Phones are one column and do not show it. The ticket says no layout change, so the plan **accepts the odd cell** and the builder reports it at gate 2 with a screenshot. If the owner does not accept it, that is a new ticket, not part of this build.

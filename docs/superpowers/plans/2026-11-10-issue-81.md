## Decisions made at planning (gate 1 is pre-approved; listed so gate 2 can check them)

1. **The highlight pulse is dropped, and Hero stops firing it.** preview-d has no highlight on `#soccer` (its Soccer script only scrolls, line 675), and decision 26 says only that the link "keeps scrolling to `#soccer`". With the listener gone, Hero's `window.dispatchEvent(new CustomEvent("highlight-soccer"))` (Hero.tsx line 33) would fire into nothing, so that one line is deleted. #78's plan (its decision 4) kept the event only "until #81".
2. **Spectral italic is loaded** (`style: ["normal", "italic"]` in `layout.tsx`). The head is Spectral italic 500 in the spec, and today only the normal files load, so the browser would fake the slant. #79's section heads need the same line; if #79 adds the identical line, git merges it cleanly.
3. **Raw values stay in `Passions.tsx`, no new tokens.** The 21px serif (`.ix-h`, `.ix-ct`) has no tier in the ramp, and #78 forbids editing `--text-*`. One local constant holds the shared serif classes. The eyebrow label uses `text-h2` (13px, the existing section-label tier) with `leading-[1.4]`; the spec's 12.9px is 0.1px smaller. Spacing that the spec measures off-scale stays exact: `mt-[55px]`, `max-w-[536px]`.
4. **No `Reveal` fade and no image hover zoom.** The spec has neither, and #78's hero dropped `Reveal` too. Until #79 and #80 land, Passions is the only section below the hero that does not fade in.
5. **Own wrapper, not `Section.tsx`.** `Section` is 960px with `py-16`; the spec is the 1004px column with a rule on the section. `Section.tsx` stays untouched so the sections still using it do not move.
6. **The id moves to the `<section>`**, with `scroll-mt-24` (the spec's `scroll-margin-top: 96px`), so the Soccer link lands with the rule 96px below the top of the window.
7. **Check port is 3081, not 3000** (owner dispatch, #77). The Done-when names localhost:3000. Gate 2 says so.
